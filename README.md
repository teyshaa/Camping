# HikeManager

**Посилання на репозиторій:**[ (https://github.com/teyshaa/Camping)](https://github.com/teyshaa/Camping)

## Картка проєкту

### Склад команди та відповідальність учасників
* **Юркевич Анастасія** - Інтерфейс WinForms - створення форм, кнопок, меню, DataGridView, переходів між вікнами, оформлення інтерфейсу
* **Петричкович Анастасія** - База даних - проєктування таблиць для маршрутів, походів, учасників, спорядження та витрат; підключення SQL-бази до C# через ADO.NET; додавання, редагування, видалення і отримання даних
* **Комар Христина** - Основна логіка походів - створення та редагування походів, робота з маршрутами, додавання учасників, перевірка введених даних
* **Решетівська Анастасія** - Спорядження та фінанси - генерація списку спорядження, облік витрат, автоматичний розрахунок загального бюджету та суми на одного учасника, експорт списку у TXT/PDF
### Проблема
Організація гірського походу потребує одночасного планування маршруту, складу учасників, необхідного спорядження та фінансових витрат. При використанні окремих таблиць, нотаток або текстових документів інформація може бути розпорошеною, а розрахунок витрат та формування списку спорядження доводиться виконувати вручну.
Програмний продукт HikeManager призначений для централізованого планування гірських походів та збереження всієї необхідної інформації в одному застосунку.
### Цільові користувачі
* організатори туристичних походів;
* керівники туристичних груп;
* учасники туристичних клубів;
* користувачі, які самостійно організовують групові походи.

### Мета
Мета проєкту - розробити настільний застосунок для зручного планування гірських походів, який дозволить організатору керувати маршрутами та учасниками, формувати список необхідного спорядження, розраховувати витрати на похід і зберігати інформацію про проведені та заплановані походи.

### Короткий опис основних можливостей
* додавання, редагування та видалення маршрутів.
* збереження інформації про маршрут: назва, місце, складність, тривалість, довжина.  
* створення нового походу.  
* вибір маршруту для походу.  
* додавання та видалення учасників.  
* формування списку необхідного спорядження.  
* розрахунок витрат на транспорт, харчування, страхування та інші потреби.  
* розрахунок загальної вартості походу та суми на одного учасника.  
* перегляд попередніх/запланованих походів.  
* збереження інформації в локальній SQL-базі.  
* експорт списку спорядження у файл.
